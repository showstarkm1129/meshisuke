## 指示書との差分・特記事項

### Vite バージョンが 8 だった件

指示書（Phase 0 指示書 タスク2）は Vite 6 以降を前提として記述されていたが、実際のテンプレートは **Vite 8 / React 19 / TypeScript 6.x / ESLint 10** で生成されていた。主な影響は以下の通り:

- `eslint-plugin-react-hooks`（v7.1.1）と `eslint-plugin-react-refresh`（v0.5.2）はテンプレートに既に含まれており、追加インストール不要だった（マネージャーが事前に確認済みで、指示書にもその旨注記あり）。
- `eslint.config.js` に `reactHooks.configs.flat.recommended` と `reactRefresh.configs.vite` が既に extends されていたため、これらへの追記は不要だった（指示書の「重要」注記の通り）。
- `tsconfig.app.json` に `noUnusedLocals` / `noUnusedParameters` / `noFallthroughCasesInSwitch` が既に含まれており、不足は `strict: true` のみだった（指示書注記の通り）。
- `tsconfig.app.json` には Vite 8 固有の `"erasableSyntaxOnly": true` と `"lib": ["ES2023", "DOM"]` 等の設定が存在する。変更指示がないため手を触れていない。

### README.md のバージョン表記

指示書（タスク6）の README テンプレートには `Vite 6.x` / `TypeScript 5.x` / `Node.js 20以上` と記載されていたが、coding-agent への作業指示（作業7）では実際のバージョン（`Vite 8.x` / `TypeScript 6.x` / `Node.js 22 LTS`）で記述するよう明示されていた。作業指示に従い実際のバージョンで記載した。
